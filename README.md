# Robotic-Arms
with ESP32, four motos and some sensors.

本系统基于ESP32实现机械臂控制，采用主从控制结构。
主端通过四个电位器采集关节角度信息，经过ADC滤波和角度映射后生成目标角度，再控制从端四个舵机运动。
同时系统加入了速度限制和平滑算法，使机械臂运动更加稳定，机器自带的小蓝灯提示状态，拥有一键复位按钮。

此外，通过ESP32 WiFi建立网页服务器，实现机械臂状态监控和控制模式切换，可以在电位器控制模式和Python串口手势控制模式之间切换。
系统还利用Preferences库保存舵机位置，实现断电保存。
